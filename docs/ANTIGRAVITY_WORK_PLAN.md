## 2. Architectural Adherence & Standards Review

1. **Deterministic Core vs. AI Isolation (ADR-009)**:
   - AI models never directly mutate live orders or inventory.
   - Products generated by AI are stored as `DRAFT` until a verified seller invokes `approveListing()`.
2. **Timing-Safe HMAC Verification (ADR-008)**:
   - Razorpay webhook payloads and payment orders verify signatures using `crypto.timingSafeEqual`, preventing side-channel attacks.
3. **Pessimistic Concurrency & ACID Integrity (ADR-002)**:
   - Flash-sale inventory deductions lock rows via Prisma interactive transactions.
   - 200 concurrent requests against 50 items consistently yield 50 fulfilled, 150 rejected, and exactly 0 remaining stock.
4. **Idempotent Asynchronous Processing (ADR-003)**:
   - SQS worker verifies unique idempotency keys before processing outbox events, preventing duplicate inventory deductions or double billing.
5. **Least-Privilege Cloud Infrastructure (ADR-004)**:
   - Database resides in isolated subnets with no internet gateway.
   - ECS Fargate tasks run in private subnets behind dual NAT gateways.
   - ALB handles TLS termination with automatic HTTP-to-HTTPS redirect.
