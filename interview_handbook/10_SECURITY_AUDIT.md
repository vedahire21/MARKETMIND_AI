# MarketMind AI — Comprehensive Security Audit & Threat Review

## 1. Executive Security Posture
The application demonstrates an **adversarial, defense-in-depth security posture**. Sensitive secrets are managed via AWS Secrets Manager, cryptographic payment verification uses constant-time byte comparisons, and AI models operate under strict schema isolation boundaries.

---

## 2. Threat Vector Review & Classification

| Threat Vector | Classification | Current Defense Mechanism in Codebase | Reference |
| :--- | :--- | :--- | :--- |
| **SQL Injection** | **GOOD** | 100% of database queries use Prisma ORM parameterized queries. Zero raw SQL queries (`$queryRawUnsafe`) exist in the application. | `shared/prisma.ts` |
| **Timing Side-Channel Attacks** | **GOOD** | Razorpay payment callbacks & webhook signatures verified using `crypto.timingSafeEqual`. | `payments.service.ts` |
| **Broken Object Level Auth (IDOR)**| **GOOD** | Queries strictly filter on `customerId: req.user.userId` or `sellerId: req.user.sellerId`. Customers cannot view foreign orders. | `orders.service.ts:L90` |
| **Prompt Injection & LLM Jailbreak**| **GOOD** | Amazon Bedrock Guardrails filter PII and toxic prompt overrides; tools enforce strict regex `^ord-[a-zA-Z0-9_-]+$`. | `ai.schema.ts`, `supportAgent.service.ts` |
| **AI Unauthorized State Mutation** | **GOOD** | ADR-009 State Isolation: Listings generated by Copilot are strictly forced to `DRAFT` status and require human seller authorization. | `ai.service.ts:L36` |
| **Credential Stuffing & DoS** | **GOOD** | In-memory sliding-window rate limiters enforce 10 requests / 15 minutes on `/auth/login` and 100 req / 15 min globally. | `rateLimiter.ts`, `index.ts` |
| **Replay Attacks** | **GOOD** | Webhook deduplication using `ProcessedEvent` table prevents duplicate processing of replayed payloads. | `payments.service.ts:L172` |
| **Network Perimeter Exposure** | **GOOD** | 3-tier VPC with database on isolated subnets; ECS containers accept traffic only from ALB security group. | `infra/terraform/security_groups.tf` |
| **Container Privilege Escalation** | **GOOD** | Dockerfiles execute under unprivileged `appuser` (UID 1000) rather than `root`. | `server/Dockerfile` |
| **Distributed Rate Limiting** | **MEDIUM** | Current rate limiter is in-memory (per container instance). Under multi-instance ECS auto-scaling, rate limits should be backed by Redis. | `rateLimiter.ts` |
| **Secrets in Local `.env`** | **LOW** | Local development uses `.env`. Production Terraform uses AWS Secrets Manager (`secrets.tf`) with automatic container injection. | `infra/terraform/secrets.tf` |
| **XSS / Content Injection** | **GOOD** | React 18 automatic JSX output encoding prevents reflected XSS; Helmet sets strict Content-Security-Policy headers. | `server/src/index.ts:L23` |
